# Web Frontend

The Nova ACT Web Frontend provides a visual interface for managing and monitoring Nova ACT operations. This guide covers setup, configuration, and usage of the web interface.

## Overview

The web frontend is built with React and TypeScript, offering:
- Real-time monitoring of Nova ACT operations
- Visual configuration management
- Results visualization
- Interactive debugging tools

## Installation

1. Navigate to the frontend directory:
```bash
cd src/frontend
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

## Configuration

The web frontend can be configured through:
- Environment variables
- Configuration files
- Runtime settings

See the [Project Structure](project-structure.md) documentation for details about how the web frontend fits into the overall Nova ACT ecosystem.
